### Inbox Zero Automation

- Canonical prompt: Design a repeatable system for achieving and maintaining inbox zero. Provide explicit deliverables: 1. Goal: A clear, measurable objective for inbox zero (e.g., 'Process all emails within 24 hours, with zero unread emails daily'). 2. Required Inputs: List all necessary inputs (e.g., email access, categorization criteria, time allocation). 3. Decision Rules: Step-by-step rules for processing emails (e.g., 'If email is actionable and takes <2 minutes, do it immediately; if >2 minutes, schedule it; if informational, archive; if spam, delete'). 4. Failure Points: Identify potential breakdowns (e.g., high-volume periods, unclear categorization, lack of follow-up). 5. Next Best Action: Specify the immediate next step to implement the system (e.g., 'Set up email filters based on categorization criteria'). Ensure the output is practical for immediate use by a small team, with no assumptions about tools or platforms.
- Final house prompt: Craft a system to consistently achieve inbox zero. Deliverables: 1. Objective: Define a measurable target (e.g., 'Process all emails within 24 hours, zero unread daily'). 2. Inputs: List necessary resources (e.g., email access, categorization criteria, time allocation). 3. Rules: Outline processing steps (e.g., 'If actionable <2 min, do now; >2 min, schedule; informational, archive; spam, delete'). 4. Risks: Identify potential failures (e.g., high volume, unclear categories, follow-up gaps). 5. Action: State the next step to deploy the system (e.g., 'Set up email filters'). Ensure practicality for a small team, independent of specific tools.
